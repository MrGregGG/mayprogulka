# Майская прогулка — карта маршрутов (MVP)

Демонстрационное веб-приложение для просмотра GPX-маршрутов Майской прогулки за 2024–2026 годы.

## Возможности

- карта на MapLibre GL JS с подложками OpenFreeMap (светлая и тёмная);
- отображение нескольких GPX-треков одновременно;
- фильтры по году, типу маршрута, дистанции и месту старта;
- карточки маршрутов и скачивание исходного GPX;
- административная панель Django для добавления и редактирования маршрутов;
- автоматическая проверка GPX, извлечение координат и контрольных точек;
- переключение светлой и тёмной темы с сохранением выбора в браузере.

## Требования

- Python 3.11 или новее;
- интернет для загрузки MapLibre GL JS и картографических тайлов OpenFreeMap.

## Запуск в Windows

Самый простой вариант:

1. Распакуйте архив.
2. Дважды нажмите `setup_windows.bat` и дождитесь завершения установки.
3. Дважды нажмите `create_admin_windows.bat` и создайте администратора.
4. Запустите `run_windows.bat`.

Установочные BAT-файлы используют только ASCII-команды и запускают Python напрямую из `.venv`, поэтому не зависят от активации окружения в командной строке.

Если предпочитаете ручной запуск, откройте PowerShell в папке проекта и выполните:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py load_demo_data
python manage.py createsuperuser
python manage.py runserver
```

Откройте:

- сайт: http://127.0.0.1:8000/
- админка: http://127.0.0.1:8000/admin/

Для входа в админку используйте логин и пароль суперпользователя, созданного командой `createsuperuser`.

## Запуск в Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py load_demo_data
python manage.py createsuperuser
python manage.py runserver
```

## Добавление нового маршрута

1. Откройте `/admin/` и войдите под администратором.
2. Перейдите в раздел «Маршруты» и нажмите «Добавить маршрут».
3. Заполните название, год, официальную дистанцию, тип и место старта.
4. Загрузите GPX-файл и сохраните запись.
5. Приложение проверит GPX, извлечёт геометрию, контрольные точки и координаты начала/конца трека.

Официальная дистанция хранится отдельно от длины, рассчитанной по координатам GPX. Это сделано намеренно: исходные GPX могут давать расстояние, отличающееся от опубликованной дистанции мероприятия.

## Данные демонстрационной версии

В комплект включены 13 файлов GPX за 2024, 2025 и 2026 годы. Официальные дистанции взяты из названий/архивных данных, тип маршрута указан как «Пеший» по страницам мероприятий за эти годы.

Координата начала на карте берётся из первой GPS-точки GPX. До отдельного подтверждения заказчика она обозначается как «Начало GPX-трека», а не как подтверждённая официальная точка старта мероприятия.

Места старта в демонстрационных записях заданы укрупнённо по году и требуют окончательной проверки. При необходимости их можно исправить в админке.

## Важно перед публикацией

Это учебная демонстрационная версия, а не production-развёртывание. Перед публикацией в интернете необходимо заменить `SECRET_KEY`, отключить `DEBUG`, настроить `ALLOWED_HOSTS`, HTTPS, резервное копирование и политику хранения загружаемых файлов. Не используйте `runserver` как production-сервер.

Дополнительные замечания по каждому исходному файлу приведены в `DATASET.md`.


## Карта и темы оформления

Картографические подложки подключаются через OpenFreeMap: `light_all` для светлой темы и `dark_all` для тёмной. Выбор темы сохраняется в `localStorage` браузера. Данные карты основаны на OpenStreetMap; атрибуция OpenStreetMap и OpenFreeMap отображается внизу карты.

В демонстрационной версии представлены 13 маршрутов за 2024–2026 годы. Это не полный исторический архив, указанный в исходном техническом задании.


## Карта без API-ключа

Для подложки используется OpenFreeMap, для отображения векторной карты — MapLibre GL JS.
API-ключ, регистрация и оплата не нужны.

Стили карты:
- Светлый: `https://tiles.openfreemap.org/styles/bright`
- Тёмный: `https://tiles.openfreemap.org/styles/dark`

Для работы карты требуется подключение к интернету. Дополнительная информация находится в `MAP_SERVICE_INFO.txt`.

## v0.1.7
- Исправлено: фильтры и загрузка маршрутов больше не зависят от успешного запуска карты.
- MapLibre подключается как стабильный классический browser bundle v5.24.0, а не через внешний ES-module import.

## v0.1.8 — карта и палитра

- В светлой теме маршруты используют только холодные/зелёные/фиолетовые оттенки. Оранжевый и жёлтый исключены из GPS-линий, чтобы не сливаться с дорожной сетью.
- Маркер конца маршрута изменён с оранжевого на малиновый.
- Для тёмной темы добавлено программное усиление дорожных слоёв OpenFreeMap через MapLibre `setPaintProperty`.
- Основные, второстепенные и локальные дороги получают разные уровни яркости.
- Фирменные зелёный и кораллово-оранжевый акценты сайта стали более чистыми и яркими; нейтральная база стала спокойнее.


## v0.1.9 — две самостоятельные темы

Светлая тема:
- белая база;
- чёрная типографика;
- кислотно-зелёный акцент;
- без оранжевого в интерфейсе и GPS-маршрутах.

Тёмная тема:
- почти чёрная база;
- белая типографика;
- яркий оранжевый акцент;
- зелёные элементы полностью заменяются оранжевыми.

GPS-палитры переключаются вместе с темой:
- light: чёрный / серый / кислотно-зелёные оттенки;
- dark: оранжевые / янтарные / белые / серые оттенки.


## v0.2.0 — строгие тематические палитры маршрутов
