# Майская прогулка — интерактивная карта маршрутов

Учебный проект для просмотра и сравнения маршрутов Майской прогулки. В демонстрационной версии представлены 13 GPX-маршрутов за 2024–2026 годы.

## Возможности

- Интерактивная карта с отображением нескольких маршрутов одновременно.
- Фильтрация по году, дистанции, типу маршрута и месту старта.
- Светлая и тёмная темы оформления.
- Просмотр информации о маршрутах и скачивание GPX-файлов.
- Добавление, редактирование и удаление маршрутов через админ-панель Django.

## Запуск

Требуется Python 3.11+ и подключение к интернету.

1. Запустите `setup_windows.bat` для установки зависимостей и загрузки маршрутов.
2. Запустите `run_windows.bat` для запуска сайта.
3. Для создания администратора используйте `create_admin_windows.bat`.

**Сайт:** http://127.0.0.1:8000/

**Админ-панель:** http://127.0.0.1:8000/admin/
